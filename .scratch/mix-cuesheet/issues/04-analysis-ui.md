# 04：分析流程畫面

**What to build:** 使用者在確認畫面按下「開始分析」後，畫面進入分析中狀態：顯示目前階段（下載中、切割中、辨識中）、「第 n／N 段」的文字和進度條，辨識到的曲目會即時出現在表格上。表格欄位有封面縮圖、開始時間、演出者、曲名和 Shazam 連結；點開始時間會在 YouTube 跳到影片的該秒數；沒有封面資料時欄位留白。分析完成後顯示完成狀態和最終曲目表；出錯時顯示錯誤訊息。之後使用者可以再貼新的網址重新分析

請參考 spec 的「前端畫面與狀態」

**Blocked by:** 03：分析流程後端（tracer bullet）

**Status:** ready-for-agent

- [ ] 按下「開始分析」會建立分析任務並訂閱任務事件串流
- [ ] 前端以 EventSource 接收事件，並轉成 signals 驅動畫面
- [ ] 分析中顯示階段文字、「第 n／N 段」和進度條
- [ ] 每次收到曲目表快照時，整份替換表格內容，不逐筆累加
- [ ] 表格欄位：封面縮圖（無資料時留白）、開始時間、演出者、曲名、Shazam 連結
- [ ] 開始時間連到 YouTube 影片的該秒數（`&t=<秒數>s`），在新分頁開啟
- [ ] 完成時顯示完成狀態和最終曲目表；出錯時顯示後端傳來的錯誤訊息
- [ ] 完成或出錯後可以回到輸入網址的狀態，重新分析另一支影片
- [ ] 所有介面文字使用繁體中文，樣式自己寫 CSS
- [ ] 手動驗證：從貼網址到看到完整曲目表，整個流程都能在畫面上操作完成
