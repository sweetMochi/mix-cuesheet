# 02：網址驗證與影片預先解析

**What to build:** 使用者在首頁貼上 YouTube 網址後，畫面會進入「解析中」，接著顯示確認畫面，內容包括混音影片的標題、長度和預估片段數，並有一個「開始分析」按鈕（按鈕在下一張 ticket 才會接上實際的分析流程）。網址不合法、是純播放清單、影片是會員限定或私人、影片不存在，或長度超過 3 小時時，畫面會以繁體中文顯示明確的錯誤原因；超過長度上限時也會一併顯示影片長度。這個階段只讀取影片資訊，不下載音訊

請參考 spec 的「網址驗證」「切段規劃」模組和 API 契約中的「預先解析影片」

**Blocked by:** 01：專案骨架與工具檢查

**Status:** ready-for-agent

- [ ] 網址驗證純函式接受 `youtube.com/watch?v=`、`youtu.be/`、帶 `&list=` 的影片網址，並取出正確的影片 ID（忽略清單參數）
- [ ] 網址驗證純函式拒絕純播放清單網址、非 YouTube 網址和格式錯誤的字串，並回傳可以區分的錯誤原因
- [ ] 切段規劃依影片長度、片段長度和步距算出片段起始秒數：從 0 開始，每隔一個步距一段；最後一段剩不到 5 秒時略過
- [ ] 預估片段數直接使用切段規劃計算，之後實際切段也必須使用同一套計算
- [ ] 預先解析端點以 yt-dlp 讀取影片資訊（不下載），回傳影片 ID、標題、長度（秒）和預估片段數
- [ ] 預先解析端點會把 yt-dlp 的錯誤轉成使用者看得懂的原因（會員限定、私人影片、影片不存在等）
- [ ] 影片超過 3 小時時，預先解析端點回傳超過上限的錯誤，並附上影片長度
- [ ] 前端依序呈現「輸入網址 → 解析中 → 確認畫面或錯誤訊息」，所有文字使用繁體中文
- [ ] pytest 涵蓋網址驗證的合法與不合法輸入，以及切段規劃（含最後一段太短被略過的情況）
- [ ] 手動驗證：貼上一支真實的混音影片網址，確認畫面顯示的標題、長度和片段數正確
