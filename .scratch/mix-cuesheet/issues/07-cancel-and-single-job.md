# 07：取消與單一任務限制

**What to build:** 分析進行中時，使用者可以按「取消」停止任務。系統會停止送出新的辨識請求、中止進行中的 yt-dlp 和 FFmpeg 子程序、刪除暫存資料夾，畫面顯示「已取消」，之後可以重新貼網址。分析中網址輸入和送出按鈕都會停用；就算直接呼叫 API，後端在已有任務執行時也會拒絕建立第二個任務

請參考 spec 的「分析任務執行器」模組和 API 契約中的「建立分析任務」「取消任務」

**Blocked by:** 04：分析流程畫面

**Status:** ready-for-agent

- [ ] 取消任務端點會對指定的任務送出取消信號
- [ ] 收到取消信號後，任務執行器不再呼叫辨識器，並送出「已取消」事件
- [ ] 取消時會中止進行中的 yt-dlp 和 FFmpeg 子程序，不留下孤兒程序
- [ ] 取消後任務專屬的暫存資料夾被刪除
- [ ] 已有任務在執行時，建立分析任務端點回傳衝突錯誤
- [ ] 前端在分析中顯示「取消」按鈕，並停用網址輸入和送出按鈕
- [ ] 取消後畫面顯示「已取消」，並可以回到輸入網址的狀態
- [ ] pytest 透過分析任務執行器驗證：取消後送出「已取消」事件、不再呼叫辨識器、暫存資料夾被刪除
- [ ] 手動驗證：分別在下載階段和辨識階段取消，確認子程序已結束、暫存檔已刪除
